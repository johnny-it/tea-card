# Карточка товара «Ананасовый улун»

Адаптивная карточка товара для интернет-магазина чая. Проект выполнен без
фреймворков, сборщиков и сторонних UI-библиотек — только HTML5, CSS и
JavaScript.

## Возможности

- четыре интерактивные фасовки;
- обновление цены, старой цены и артикула без перезагрузки страницы;
- доступные состояния `aria-pressed` и `focus-visible`;
- SVG-иконка корзины, наследующая цвет кнопки;
- адаптивная desktop-first вёрстка;
- БЭМ-именование классов и логическое разделение CSS.

## Запуск

Откройте файл `index.html` в браузере. Дополнительная установка зависимостей
или запуск локального сервера не требуются.

## Адаптивность

Стили построены по принципу desktop-first:

- базовая версия — шире `1024px`;
- до `1024px` — компактная двухколоночная карточка;
- до `767px` — одноколоночная мобильная компоновка;
- до `479px` — уменьшенные отступы и типографика для узких экранов.

Контрольные ширины для визуальной проверки: `1440px`, `768px` и `375px`.
